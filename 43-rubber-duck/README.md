# 43 · 🦆 Rubber Duck

A rubber duck debugging buddy that sits right on top of your code editor. Tell it your bug and it listens with tiny head tilts. Tap it and it squeaks (big squash and stretch). Drag it and it floats like it's in a bathtub, the code wobbling under the ripples. On the third squeak it waddles over to the broken line, pecks the red error underline until it swells up like a balloon and pops, the fix types itself in, the console prints "✓ 0 errors" and the duck puts on tiny pixel sunglasses. Tap again for the next bug. One HTML file, no libraries, all drawn on a canvas.

```

```
- `color`: the duck's colour as a hex code, e.g. `?color=ff7ab6` for a pink duck or `?color=6fd3ff` for a blue one

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: the list of bugs the duck finds (broken line, what's wrong, the fix, the error message), how many squeaks until it fixes the bug, what it says, sound
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
