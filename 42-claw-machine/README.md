# 42 · 🧸 Claw Machine

A glowing arcade claw machine at night, packed with plushies. Drag to aim, tap to drop. The claw is famously weak: it grabs a bear and lets it slip ("nooo"), then carries a bunny almost to the chute and drops it ("so close…"). The third try is rigged: the claw ignores where you aimed, glides over to a little plush heart holding a sign that says "Delly ♥", carries it to the chute, the prize door pops open with confetti and the machine prints a ticket: "you won: me". Change the name in the link and send it to your person. One HTML file, no libraries, all drawn on a canvas.

## Change it without coding
```
https://sicscod.github.io/drops/42-claw-machine/?name=Delly&msg=you%20won:%20a%20date
```
- `name`: the name on the heart's little sign
- `msg`: the ticket line, written as `label: big word` (default `you won: me`)
- `hue`: heart + neon colour, 0–360, e.g. `?hue=200` for a blue heart

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: which try is rigged, what you say when it drops a plush, the marquee sign, claw speed, sound
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
