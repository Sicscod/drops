# 23 · 💗 Neon Sign

Her name as a real neon sign: bent glass tubes on a clear acrylic board, mounting clips, a cable running down a dark brick wall. The tubes strike one by one with that stuttering flicker, the glow bleeds onto the bricks and the wet floor throws back a rippling reflection, then a small heart and "you're my favourite light" switch on. Tap to change the colour (pink → cyan → amber), drag a finger across the glass to make it buzz and spark. Change the name in the link and send it to your person. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/23-neon-sign/?name=Delly

## Change it without coding
```
https://sicscod.github.io/drops/23-neon-sign/?name=Delly&line=happy%20birthday%20baby&hue=280
```
- `name`: the big neon word (any name, it is bent into tubes automatically)
- `line`: the small line underneath
- `hue`: the first colour as a hue from 0 to 360, e.g. `?hue=280` for violet, `?hue=130` for green

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: name, line, the three tap colours, heart colour, script font, how fast the letters strike, which letter has the loose electrode
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
