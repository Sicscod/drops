# 09 · 🌹 3D Rose

A rose that never dies: 18,000 glowing particles fly together into a 3D rose, it slowly blooms and spins, petals drift down, and "for Delly" fades in underneath. Tap anywhere to make it rain petals. Change the name in the link and send it to your person. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/09-rose/?name=Delly

https://github.com/Sicscod/drops/raw/main/09-rose/demo.mp4

## Change it without coding
```
https://sicscod.github.io/drops/09-rose/?name=Delly&sub=happy%20birthday
```
- `name`: the name under the rose
- `sub`: the small line under the name
- `petal` / `tip`: petal colours, e.g. `?petal=%23b026ff&tip=%23f0c8ff` for a purple rose

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: name, colours, how far it opens, spin speed
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
