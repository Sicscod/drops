# 06 · ✨ Written in the Stars

Her name, drawn as a constellation. Stars fly in, connect into her name, and a shooting star crosses the sky when she taps. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/06-written-in-the-stars/?name=Delly

https://github.com/Sicscod/drops/raw/main/06-written-in-the-stars/demo.mp4

## Send it without coding
Just change the link and send it:

```
https://sicscod.github.io/drops/06-written-in-the-stars/?name=Delly&line=you%20are%20my%20whole%20sky
```

- `name`: her name
- `line`: the message under the stars
- `sub`: the small text below it
- `font`: any Google Font for the name (try `Allura` or `Great Vibes`)

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block at the top: name, message, star colour, how many stars
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
