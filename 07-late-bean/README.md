# 07 · ☕ late bean. — full coffee shop website

A complete, mobile-first landing page for a café: hero with a steaming cup, running menu marquee, bento menu with a working bag, counters, reviews, hours and a big footer. Everything animates on scroll. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/07-late-bean/

https://github.com/Sicscod/drops/raw/main/07-late-bean/demo.mp4

## Rename it without coding
```
https://sicscod.github.io/drops/07-late-bean/?name=Moon%20Beans&city=Almaty
```
- `name`: café name (logo, title, footer)
- `city`: city in the address

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block at the top: menu items and prices, stats, review, address, opening hours
3. Colours are in `:root` in the CSS (`--accent` is the orange)
4. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)

Works great as a first site for a real café client.
