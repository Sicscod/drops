# 51 · 🐹 Infinite Loop

Your `while (true)` loop has a body, and the body is a hamster in a wheel. The iteration counter is flying past a million, the CPU meter sits at 99% in red, the laptop fan sticker spins and smokes, sparks come off the axle and the hamster sweats with the most determined eyebrows in the editor. Press Ctrl+C: it says "not now" and runs faster. Press it again: "nyoom", it turns into a blur. Then type `break;` into the loop and the wheel stops dead. The hamster flies out in a cartoon arc, bounces off the terminal, lands sitting with dizzy stars, then gives you a tiny thumbs-up while the console prints "process exited with code 0" and the CPU drops to 3%. One HTML file, no libraries, all drawn on a canvas.

## Change it without coding
```
https://sicscod.github.io/drops/51-infinite-loop/?speed=1.5&hue=200
```
- `speed`: how fast the hamster runs, e.g. `?speed=0.6` for a sleepy one or `?speed=2` for unhinged (default 1)
- `hue`: fur colour, 0–360, e.g. `?hue=200` for a blue hamster, `?hue=20` for ginger (default 34, golden)
- `auto=1`: a cursor plays the whole thing by itself (good for screen recordings)

Tap the hamster to make it sprint harder. Tap the Ctrl+C keys (or press Ctrl+C) and watch it ignore you. Tap the empty line inside the loop, or just type `break;` on your keyboard, to end it.

3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
