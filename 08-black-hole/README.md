# 08 · 🌌 Black Hole

An Interstellar-style black hole in your browser: 16,000 particles orbit in a glowing accretion disk, light from the far side bends over the top, and the stars behind it get lensed around the edge. Drag it around, tap anywhere to feed it a cloud of stars. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/08-black-hole/

https://github.com/Sicscod/drops/raw/main/08-black-hole/demo.mp4

## Change it without coding
```
https://sicscod.github.io/drops/08-black-hole/?hot=%2388b4ff&cool=%233a2bff
```
- `hot`: inner disk colour
- `cool`: outer disk colour
- `hint`: the small text at the top

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: particle count, hole size, disk tilt, colours
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
