# 28 · 🌧️ Foggy Window

A rainy night behind fogged glass: the city is just blurred neon bokeh, raindrops run down the window and leave clear trails, and every wipe of your finger shows the sharp city through the stroke before it slowly fogs back over. After a few wipes the fog starts writing by itself, as if someone on the other side drew "Delly" and a little heart with their finger, drips running down from the letters, and a line fades in under the window: "missing you on nights like this". Change the name in the link and send it to your person. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/28-foggy-window/?name=Delly

## Change it without coding
```
https://sicscod.github.io/drops/28-foggy-window/?name=Delly&msg=missing%20you%20on%20nights%20like%20this&hue=335
```
- `name`: what gets written in the fog
- `msg`: the line under the window, e.g. `?msg=come%20over%3F`
- `hue`: main neon colour of the city (0-360), e.g. `?hue=200` for a blue night

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: name, message, neon colour, how many wipes before it writes, how fast the glass fogs back, how much rain
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
