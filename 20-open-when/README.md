# 20 · 💌 Open When

A little pile of paper envelopes, each one marked "open when…": you miss me, you can't sleep, you need a smile, it's your birthday. Tap one and it lifts off the pile, turns over, the wax seal cracks, the flap folds back and a handwritten letter slides up with doodled hearts. Tap again to fold it away. The last one says "Delly, I'm always here." Change the name and the letters in the link and send it to your person. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/20-open-when/?name=Delly

https://github.com/Sicscod/drops/raw/main/20-open-when/demo.mp4

## Change it without coding
```
https://sicscod.github.io/drops/20-open-when/?name=Delly&notes=you%20miss%20me::Look%20up,%20same%20moon,%20same%20me.|you%20are%20bored::Text%20me%20your%20worst%20joke.
```
- `name`: who the letters are for
- `notes`: the envelopes, separated by `|`, each one `title::letter` (the title finishes "open when…")
- `lastTitle`: title of the envelope on top (default "you just need me")
- `last`: the big line in that last letter (default "I'm always here.")
- `sign`: how every letter is signed (default "always, me")

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: name, letters, envelope colours, wax colour, opening speed
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
