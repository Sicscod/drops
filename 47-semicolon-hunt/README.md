# 47 · 🪲 Semicolon Hunt

The build fails with a red "Expected ';'" and the reason is running around your screen. The missing semicolon is alive: a tiny ";" with legs and googly eyes, scurrying across the lines and knocking your letters askew. Your cursor is a flyswatter. Tap to swat. It dodges, squeezes between the parentheses of `brew()`, hops from brace to brace, dives into a string and peeks out, and every miss leaves a cartoon dent in the screen. Land the third swat and it squeaks, gets carried back and snaps into place at the end of line 8 with a click. Every knocked letter flies home, the error count drops from 1 to 0, "Build succeeded ✓", and the semicolon winks at you. One HTML file, no libraries, all drawn on a canvas.

## Change it without coding
```
https://sicscod.github.io/drops/47-semicolon-hunt/?speed=1.5&hue=46
```
- `speed`: how fast the bug runs, 0.3–3, e.g. `?speed=2` (good luck)
- `hue`: the bug's colour, 0–360, e.g. `?hue=0` for a red one or `?hue=200` for blue (the swatter picks a matching colour)
- `auto=1`: a swatter plays the whole hunt by itself (good for screen recordings)

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: the code snippet, which line loses its `;`, the hiding spots (any text in your code: parentheses, braces, strings), how many swats it dodges, its quips, the error and success text, sound
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
