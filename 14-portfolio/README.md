# 14 · 💻 Delly.dev

A full developer portfolio in one file: it boots like a terminal, then lifts away to a hero with your name, an about section with counting stats, a projects grid where every thumbnail is drawn live on canvas (tap a card to lift it), your stack with skill meters, an experience timeline that fills as you scroll, and a contact form with a sending state and a success screen. Dark, fast, mobile-first. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/14-portfolio/

https://github.com/Sicscod/drops/raw/main/14-portfolio/demo.mp4

## Change it without coding
```
https://sicscod.github.io/drops/14-portfolio/?name=Delly&role=Rust%20developer&city=Berlin&accent=FF8A4C
```
- `name`: your name (also becomes the logo, e.g. `delly.dev`)
- `role`: the main line under your name
- `city`: where you are based
- `email`: the address under the form
- `accent`: the accent colour as hex without `#`, e.g. `?accent=FF8A4C`
- `intro=0`: skip the terminal boot intro

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Edit the `CONFIG` block: projects (name, year, text, tags, thumbnail style), skills, jobs, social links
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)

The form is a demo (it shows a success state without sending anything). Hook it up to Formspree or your own endpoint when you go live.
