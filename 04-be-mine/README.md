# 04 · 💌 Be Mine

Ask your crush out with a website. The **No** button runs away, **Yes** grows, and a "Yes" ends in heart fireworks. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/04-be-mine/?name=Delly

https://github.com/Sicscod/drops/raw/main/04-be-mine/demo.mp4

## Send it without coding
Just change the link and send it:

```
https://sicscod.github.io/drops/04-be-mine/?name=Delly&date=Saturday,%208%20pm
```

- `name`: her name
- `date`: when you'll pick her up

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file**
2. Open `index.html` and edit the `CONFIG` block at the top: question, No-button texts, final message
3. Colors are in `:root` in the CSS
4. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
