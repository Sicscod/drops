# 13 · 👟 Sneaker Drop

A full sneaker release store in one file: an invented brand, a hand-drawn SVG sneaker that floats and tilts in the hero, a live countdown to release day, colourway swatches that flip and recolour the shoe, a size grid with sold-out sizes, Add to bag with a bag counter and a toast, a lookbook rail, specs, reviews and a footer. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/13-sneaker-drop/

https://github.com/Sicscod/drops/raw/main/13-sneaker-drop/demo.mp4

## Change it without coding
```
https://sicscod.github.io/drops/13-sneaker-drop/?brand=KORE&model=Drift%2007&price=160&date=2026-12-24T10:00
```
- `brand`: the brand name in the nav and the giant footer word
- `model`: the shoe name in the hero (the last word gets the outline style)
- `price`: the price everywhere on the page
- `date`: release date and time for the countdown (if it's in the past, a demo timer runs)

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Edit the `CONFIG` block: colourways (every part of the shoe has its own colour), sizes, sold-out sizes, specs, reviews
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
