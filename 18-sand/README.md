# 18 · ⏳ Sand

A falling-sand simulation you can play with for way too long. Drag your finger to pour glowing sand that piles up, slides down the slopes and settles; the colour slowly drifts while you pour, so every pile turns into striped layers like sand art in a bottle. Tap to switch to water (it flows sideways and the sand sinks through it) or sparks that fizzle out, double-tap to tilt the box and pour everything out. A real grid simulation on typed arrays with crisp, scaled pixels, so it stays fast on phones. One HTML file, no libraries.

## Change it without coding
```
https://sicscod.github.io/drops/18-sand/?hue=200&speed=1.5&grain=4
```
- `hue`: the starting colour from 0 to 360 (e.g. `28` amber, `200` sky, `330` rose); it drifts from there while you pour
- `speed`: simulation speed, `0.5` slow motion to `2` fast
- `grain`: grain size in pixels, `2` fine sand to `8` chunky pixels

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Open `index.html` and edit the `CONFIG` block: colour drift speed, stripe length, pour size, how much comes out, glow
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
