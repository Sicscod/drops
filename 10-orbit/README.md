# 10 · 🪐 Orbit

A full SaaS landing page in one file: sticky nav, a hero with a 3D planet drawn on canvas (rings, orbiting dots, floating event cards), logo strip, features grid, a live product mock of a calendar week, pricing with a Monthly / Yearly toggle that counts the prices down, testimonials, an FAQ accordion, a dark CTA with a mini planet and a footer. Every animation runs from one requestAnimationFrame loop. One HTML file, no libraries.

**Live demo:** https://sicscod.github.io/drops/10-orbit/

https://github.com/Sicscod/drops/raw/main/10-orbit/demo.mp4

## Change it without coding
```
https://sicscod.github.io/drops/10-orbit/?name=Lumen&accent=%23FF5A1F
```
- `name`: the product name (nav, hero copy, FAQ answers, footer)
- `accent`: the brand colour (planet, buttons, highlights), e.g. `%23FF5A1F` for orange

## Make it yours
1. Open [`index.html`](index.html) → **Download raw file** (it's the whole project, one file)
2. Edit the `CONFIG` block: hero line, logos, features, plans and prices, yearly discount, testimonials, FAQ
3. Publish for free: **Settings → Pages → main** (or drop the folder on Vercel)
